# networking-agent

This is an [eve](https://eve.dev) agent bootstrapped alongside the other doresume agents.

## Getting started

```bash
bun run dev:networking-agent
```

Or from this package:

```bash
eve dev
```

Edit `agent/instructions.md` for identity and behavior. Configure the model in `agent/agent.ts`.
