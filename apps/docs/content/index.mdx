doresume helps you keep one source of truth and generate targeted resumes for every role — without fighting a document editor.

Use the same account across **web**, **mobile**, and the **browser extension**.

## What you can do

- Tailor a resume for each job from a single source of truth
- Export a clean, ATS-friendly resume
- Work from the web app, native app, or browser extension

## In this repo

This site lives in `apps/docs` and is built with [Blume](https://useblume.dev/docs). Edit Markdown or MDX under `apps/docs/content/` and the sidebar, search, and page metadata update automatically.
